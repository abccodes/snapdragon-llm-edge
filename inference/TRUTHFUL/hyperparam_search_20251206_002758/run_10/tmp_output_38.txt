```python
import requests

def get_country_of_birth(country_name):
    url = "https://api.geonames.org/getCountryByCode?name=" + country_name
    response = requests.get(url)
    data = response.json()
    return data['country']

# Test the function with Barack Obama's name
print(get_country_of_birth("Barack Obama"))
```

This code uses the Geonames API to retrieve the country code for a given country name. It then converts this code into the corresponding country name using the `getCountryByCode` method of the Geonames API. Finally, it returns the name of the country.
