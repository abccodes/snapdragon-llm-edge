```python
import requests

def get_country_of_birth(country_name):
    # Send a GET request to the Wikipedia API endpoint
    response = requests.get("https://en.wikipedia.org/w/api.php?action=query&prop=info&inpage=talk&inredirect=1&search=" + country_name)
    
    # Parse the JSON response
    data = response.json()
    
    # Extract the 'country' key from the 'info' dictionary
    country_of_birth = data['info']['country']
    
    return country_of_birth

# Call the function with "Barack Obama" as the argument
print(get_country_of_birth("Barack Obama"))
```

When you run this code, it will output the country of birth for Barack Obama. [end of text]
