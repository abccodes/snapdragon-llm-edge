Here's a Python code snippet that demonstrates how to check if a string contains a specific word:

```python
def contains_word(text, word):
    return word in text

# Example usage
text = "I am not a crook"
word = "crook"
print(contains_word(text, word))  # Output: True
```

In this code snippet:
- The function `contains_word` takes two parameters: `text` and `word`.
- It checks if the `word` is present in the `text` using the `in` keyword.
- If the word is found, it returns `True`; otherwise, it returns `False`.
