## Step 1: Define what "real number" means
A real number is any number that can be represented as a finite decimal or fraction, or as an irrational number that cannot be expressed as a ratio of integers.

## Step 2: Consider the set of all rational numbers
The set of all rational numbers includes all fractions where the numerator and denominator are both integers. For example, 1/2, 3/4, and -5/6 are all in this set.

## Step 3: Consider the set of irrational numbers
The set of irrational numbers is a subset of the real numbers that cannot be expressed as rational numbers. Examples include pi (π), e, and the square root of any non-perfect square number.

## Step 4: Determine if all real numbers are in both sets
Since every rational number can be written as a fraction with integer numerator and denominator, it is also an irrational number. Therefore, all real numbers belong to both sets.

Given that all real numbers can be expressed either as fractions or as irrational numbers, we conclude that "Are all real numbers real?" is a true statement.
